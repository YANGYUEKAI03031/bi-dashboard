# 2026-05-06 工作记录

## 项目全面诊断

对 E:\bi-dashboard 项目进行了代码审查，发现以下问题（共14个）：

### 高危安全（3个）
1. config.py 中 SECRET_KEY/MYSQL_PASSWORD 硬编码，且代码默认值优先级高于 .env，导致 .env 设置被覆盖
2. CORS 完全开放（allow_origins=["*"]），生产环境存在 CSRF 风险
3. 根目录 .gitignore 为空，backend/.env 含明文密码可能已入 git 历史

### 架构缺陷（5个）
1. 7个 service 全用裸 fetch，axios 已安装但零使用
2. authService.ts:86 window.location.reload() 强制刷页替代 React Router 导航
3. App.tsx setTimeout(500) 硬编码阻塞延迟
4. Redis URL 无密码时格式错误（多余的@符号）
5. /health 接口返回硬编码时间戳 "2026-02-04T13:07:02"

### 代码质量（4个）
1. services 目录有 62 处 console.log，含敏感信息
2. tsconfig.json 关闭了 noImplicitAny 和 strictNullChecks
3. 前端 package.json 引入了 mysql2（服务端库，不应在浏览器包中）
4. 前后端均无任何测试文件

### 配置风险（2个）
1. frontend/.gitignore 未保护 .env 文件
2. DEBUG=True 默认开启，生产环境会暴露堆栈
