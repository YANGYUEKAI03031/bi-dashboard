## 2026-05-26 仪表盘暗色主题修复

  - `title` → `#e2e8f0`
  - `meta` → `#94a3b8`
  - `hint` → `#64748b`

## 2026-05-26 ReportsPage 设为只读

- **问题**：用户反馈 Reports 页面可以拖拽调整卡片大小和位置，但 Report 应该是只读的。
- **根因**：项目使用 react-grid-layout **v2.2.2**，其 API 从 v1 的 `isDraggable={false}` 改为了 v2 的 `dragConfig={{ enabled: false }}`。旧的 `isDraggable`/`isResizable` props 在 v2 中被静默忽略。
- **修复**（三管齐下）：
  1. `ReportsPage.tsx` `AutoWidthGridLayout`：用 v2 API `dragConfig={{ enabled: false }}` + `resizeConfig={{ enabled: false }}`
  2. `ReportsPage.tsx` `mergedLayout`：每个 layout 项加 `static: true`，从数据层面禁止拖拽
  3. `ReportsPage.css`：`.react-resizable-handle { display: none !important }` 隐藏手柄，`.react-grid-item { cursor: default }` 去掉拖拽光标
